# DeadOrbit

DeadOrbit is a 2D survival and exploration game set on a remote hostile planet following a failed scientific expedition. The player is the last surviving researcher tasked with restoring a planetary beacon system to signal for rescue.

## Overview

You play as a lone scientist stranded on an unknown planet after a failed expedition. The primary objective is to activate a planetary beacon system consisting of three distributed base stations. Once all stations are powered, the beacon can be activated to transmit a rescue signal.

To achieve this, the player must explore an unknown world, gather resources, and survive environmental hazards and hostile lifeforms.

The world features procedurally or semi-procedurally generated environments with varied biomes, resource nodes, and threats. Each playthrough can differ in layout, resource distribution, and environmental conditions.

A limited inventory system forces strategic resource management, while crafting and processing systems allow the transformation of raw materials into usable components, ensuring progression even when surface resources become scarce.

The gameplay focuses on simple, responsive mechanics centered around exploration, survival, and system restoration.

## Features

- 2D top-down movement system
- Resource gathering and basic combat interactions
- Three base stations required to activate a global beacon
- Hostile entities that pursue and attack the player
- Limited 8-slot inventory system
- Crafting and resource transformation system
- Environmental survival pressure and resource scarcity mechanics
- Keyboard, mouse, and gamepad input support (XInput-based)

## Technologies Used

- C#
- .NET
- MonoGame framework
- XNA-compatible rendering pipeline
- Custom input system (keyboard + mouse + gamepad abstraction)

## Getting Started

To get started with DeadOrbit, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/NikitaBerezhnyj/DeadOrbit.git
   ```

2. Navigate into the project directory:

   ```bash
   cd DeadOrbit
   ```

3. Restore dependencies:

   ```bash
   dotnet restore
   ```

4. Build and run the project:

   ```bash
   dotnet run
   ```

Make sure you have:

- .NET SDK installed
- MonoGame framework dependencies available
